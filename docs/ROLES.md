## Правила совместной работы

**Пушим прямо в `main`. Это безопасно только при жёстком владении файлами.**

| Правило | Почему |
|---|---|
| Каждый файл имеет **одного** владельца. Чужой файл не трогаем никогда | Единственная причина конфликтов при работе в общей ветке |
| Перед каждым пушем: `git pull --rebase origin main` | Без `--rebase` получим мусорные merge-коммиты и конфликты на ровном месте |
| Пушим каждые 15–20 минут, мелкими коммитами | Чем реже пуш, тем больнее конфликт |
| Нужно изменить чужой файл — пишем владельцу, не правим сами | Иначе он затрёт вашу правку своим пушем |
| `out/` в `.gitignore` — выгрузки **не коммитим** | Три человека, генерирующие одни и те же CSV, = конфликт в каждом пуше |

Команда на каждый пуш:

```bash
git pull --rebase origin main && git push origin main
```

**Общие файлы** (`run.py`, `requirements.txt`, `src/schema.py`) принадлежат **kuanyshs**.
Нужна новая зависимость — пишем ему, он добавляет.

```bash

```

Треки B и C работают на этом, пока kuanyshs не выдаст настоящие выгрузки.


### Критично

- Ассистент отвечает **только числами из выгрузок** и **обязан называть gid**, на которые опирается.
  ТЗ запрещает чёрный ящик; галлюцинация на демо дороже отсутствия ассистента.
