Проверь каждую вручную и доведи:


## Жёсткие правила для ассистента

- Отвечает **только числами из выгрузок**, ничего не выдумывает.
- **Обязан называть gid**, на которые опирается.
- Выводы — как гипотезы, а не утверждения о виновности.
- Отвечает **по-русски**. Без явного требования в системном промпте модель
  отвечает по-английски — проверено.
- При отсутствии ключа или сети работает **шаблонный фолбэк**. Демо не должно
  зависеть от вайфая в зале.
