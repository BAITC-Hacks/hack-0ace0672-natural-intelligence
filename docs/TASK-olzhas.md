### API, который тебе отдаёт бэк

```
GET  /api/graph          {nodes:[{id,role,priority,cluster,depth,is_seed}], edges:[{source,target,sum_kzt,n_tx}]}
GET  /api/node/{gid}     карточка + top_senders/top_receivers
GET  /api/top            топ-лист из top_nodes.csv
GET  /api/clusters       кластеры
GET  /api/roles          {роль: количество}
POST /api/ask            {question} -> {answer, cited_gids, mode}
```

`/api/ask` вызывает `src.agent.answer()` — это файл narekdavtyan228-svg. Если он ещё не готов,
роут вернёт шаблонный ответ; ничего не сломается.

### B2. Довести схему сети (30 мин)

Что стоит улучшить в текущей версии:

- **Легенда ролей** сейчас статичная — подтяни реальные количества из `/api/roles`,
  чтобы было видно «distributor — 67».
- **Толщина рёбер** по `sum_kzt` сейчас логарифмическая и почти незаметна. Подбери так,
  чтобы крупные потоки читались с проектора.
- **Фильтр по роли** — чекбоксы или клик по легенде, чтобы показать только `coordinator`
  и `consolidator`. На демо это сильный ход: «вот кто в сети главный».
- **Подпись у крупных узлов** — gid у топ-10 прямо на схеме, чтобы жюри видело их без клика.

**Готово:** схему можно показать с проектора и в ней видно структуру, а не кашу.

### B3. Проверить поиск на краевых случаях (15 мин)

Граф на экране ограничен 500 узлами (топ-120 по приоритету + соседи), а всего узлов 2248.
**Жюри может назвать gid, которого нет на схеме** — сейчас поиск в этом случае молча ничего не делает.

Надо: если узел не найден в отрисованном графе — сходить в `/api/node/{gid}`, показать карточку
и честно написать «узел есть в выгрузке, но не входит в отображаемую часть графа».
Ещё лучше — подгрузить его окружение отдельным запросом.

**Это самый вероятный провал на демо.** Сделай раньше украшательств.

**Готово:** вводишь любой из 2248 gid — получаешь осмысленный результат, а не тишину.

### B4. Карточка узла (20 мин)

Сейчас показывает роль, evidence, основные числа и топ-контрагентов. Добавь:

- кнопку «показать связи» — разворачивает соседей узла на схеме;

## Жёсткие ограничения

- **Никакого npm и сборки.** React, Babel и Cytoscape — только с CDN, весь фронт
  в одном `web/index.html`. Причина: 25 баллов за воспроизводимость, `npm install`
  на машине жюри — лотерея.
- **Новая python-зависимость — через kuanyshs.** Он владеет `requirements.txt`.
- **Не рисуй все 2248 узлов.** Проверено: на 1800 узлах вкладка вешается намертво.
  Потолок в 500 задаётся в `src/mock.py::write_graph_json` — если нужно другое число,
  попроси kuanyshs.
- Текст интерфейса — по-русски.
